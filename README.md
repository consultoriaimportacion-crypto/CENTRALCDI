# CDI · Intranet Comercial

Plataforma interna del equipo comercial de CDI (Consultoría de Importación).
Construida con HTML, CSS y JavaScript vanilla — sin dependencias ni frameworks.

## Estructura

```
index.html   → estructura de la intranet
style.css    → sistema de diseño (temas claro/oscuro)
script.js    → interacciones (buscador ⌘K, temas, accesos, etc.)
```

## Departamentos

- **Gestión Comercial** — Presentación, Dashboard, Links de Pago y Accesos (Circle · Samu · GoHighLevel · Importools).
- **Entrenamiento** — Biblioteca de Objeciones, Arsenal de Testimonios y módulos en construcción.
- **Recursos Humanos** — Acceso al portal del colaborador.

## Publicar en GitHub Pages

1. Sube estos archivos a la raíz del repositorio.
2. En el repo: **Settings → Pages → Branch: `main` / root → Save**.
3. La intranet quedará disponible en `https://<usuario>.github.io/<repositorio>/`.

Todos los enlaces abren en pestaña nueva para que la intranet permanezca siempre disponible.
